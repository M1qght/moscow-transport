# Транспортные данные

Учебные остановки и направления живут в `prisma/seed.ts` с `source=DEMO`.
Их координаты относятся к центру Москвы, но состав направлений не заменяет актуальное расписание.

Для настоящих маршрутов:

```sh
npm run data:import -- --osm
```

Импортёр запрашивает route relations автобусов и трамваев, пересекающих ограниченный прямоугольник центра Москвы. Порядок остановок берёт из relation members. Одно направление — одна запись Route. Пропускает relation без номера и направления с менее чем двумя именованными остановками. OSM может содержать неполные/устаревшие сведения; это не API Мосгортранса. Лицензия данных [ODbL](https://www.openstreetmap.org/copyright), авторство сохраняется в `sourceUrl`.

Экспорт остановок из [data.mos.ru](https://data.mos.ru/opendata/752) можно загрузить вручную (JSON-массив с `Cells.Name`, `Cells.geoData.coordinates`, `global_id`) и импортировать:

```sh
npm run data:import -- --mos-file data/private/stops.json
```

Этот экспорт добавляет только остановки. Он не содержит проверенного порядка остановок в направлении, поэтому импортёр не придумывает маршруты. Для маршрутов из другого открытого источника я использую нормализованный JSON:

```json
{
  "source": "Название открытого источника",
  "sourceUrl": "https://example.org/dataset",
  "stops": [
    { "id": "source-1", "name": "Первая", "lat": 55.75, "lon": 37.61 },
    { "id": "source-2", "name": "Вторая", "lat": 55.76, "lon": 37.62 }
  ],
  "routes": [
    {
      "id": "source-bus-1-outbound",
      "number": "1",
      "title": "Первая → Вторая",
      "type": "BUS",
      "stopIds": ["source-1", "source-2"]
    }
  ]
}
```

```sh
npm run data:import -- --file data/private/routes.json
```

Весь файл валидируется до записи, импорт выполняется одной транзакцией. Повторный импорт обновляет записи по id и заменяет порядок остановок только у импортируемых направлений. Отметки и историю пользователей не удаляет. Используйте префиксы id своего источника, чтобы не смешать разные наборы. Сырые экспорты в `data/private` исключены из Git.

Загрузка транспорта не берётся из OSM или городского портала: только пользовательские отметки. Для чистой базы выставьте `SEED_DEMO=false` до первого seed. Уже добавленные демо-записи seed намеренно не удаляет.
